# VILIX - Mobile Streaming App

VILIX adalah aplikasi streaming film dan serial TV berbasis mobile yang dibangun menggunakan **Flutter** dan **Dart**. Aplikasi ini memiliki antarmuka pengguna (UI) modern berjenis *dark mode* dengan navigasi yang responsif, fitur filter/sorting lengkap, serta animasi carousel banner.

## 🚀 Fitur Utama
- **Hero Banner Carousel**: Tampilan banner interaktif dengan autoplay dan penyesuaian font dinamis.
- **Movies & TV Series Catalog**: Katalog film dengan tampilan grid 3-kolom yang presisi dan cepat.
- **Advanced Filter & Sort**: Modal bottom sheet untuk menyaring konten berdasarkan genre, negara, tahun rilis, dan kualitas video (WEB-DL, 4K, HD).
- **Smooth Navigation**: Shell navigation dengan floating top header dan bottom navigation bar.
- **Optimized Performance**: Penggunaan *cached image* untuk pemuatan poster film yang cepat dan efisien.

## 🛠️ Teknologi yang Digunakan
- **Framework**: Flutter (Dart)
- **State Management**: Provider / Riverpod / BLoC
- **Navigation**: GoRouter
- **Font**: Google Fonts (Inter, Great Vibes)
- **Packages**: `cached_network_image`, `google_fonts`
